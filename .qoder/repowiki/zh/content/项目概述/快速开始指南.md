## 简介

OpenCode 是一个现代化的开发工具平台，旨在为开发者提供高效、便捷的编程体验。本指南将帮助您在最短时间内完成 OpenCode 的安装和配置，让您快速体验核心功能。

## 系统要求

### 支持的操作系统
- **Windows**: Windows 10/11 (推荐)
- **macOS**: macOS 10.15 或更高版本
- **Linux**: Ubuntu 18.04+, CentOS 7+, Fedora 32+

### 硬件要求
- **处理器**: Intel Core i5 或同等性能的 AMD 处理器
- **内存**: 至少 8GB RAM (推荐 16GB)
- **存储空间**: 至少 5GB 可用磁盘空间
- **网络连接**: 需要稳定的互联网连接

## 安装方式

### 方式一: 使用 curl 脚本安装

这是最简单快捷的安装方式，适用于大多数用户。

```bash
# 下载并执行安装脚本
curl -fsSL https://raw.githubusercontent.com/opencode/install-script/main/install.sh | bash
```

**安装参数说明**:
- `-y`: 自动确认所有询问
- `--prefix=/usr/local`: 指定安装目录
- `--version=latest`: 指定安装版本

### 方式二: Nix 包管理器安装

对于使用 Nix 生态系统的用户：

```bash
# 使用 flakes 安装
nix run github:opencode#opencode

# 或者添加到系统配置
nix-env -iA nixpkgs.opencode
```

### 方式三: 桌面应用安装

下载官方预编译包进行安装：

1. 访问 [GitHub Releases 页面](https://github.com/opencode/releases)
2. 下载对应操作系统的安装包
3. 双击安装包按照提示完成安装

### 方式四: 源码编译安装

```bash
# 克隆源码
git clone https://github.com/opencode.git
cd opencode

# 安装依赖
bun install

# 构建项目
bun run build

# 安装到系统
bun run install
```

## 首次运行配置

### 环境变量配置

安装完成后，需要配置必要的环境变量：

```bash
# 设置 OpenCode 根目录
export OPENCODE_HOME="$HOME/.opencode"

# 添加到 PATH
export PATH="$OPENCODE_HOME/bin:$PATH"

# 配置代理 (如有需要)
export HTTP_PROXY=http://proxy.example.com:8080
export HTTPS_PROXY=https://proxy.example.com:8080
```

### 配置文件设置

OpenCode 的配置文件位于 `~/.opencode/opencode.jsonc`：

```jsonc
{
  "installation": {
    "directory": "/usr/local/lib/opencode",
    "version": "latest"
  },
  "environment": {
    "nodePath": "/usr/local/bin/node",
    "pythonPath": "/usr/local/bin/python3"
  },
  "plugins": {
    "enabled": ["copilot", "eslint", "prettier"],
    "autoUpdate": true
  }
}
```

### 初始化设置

```bash
# 启动 OpenCode 进行初始化
opencode init

# 配置用户信息
opencode config set user.name "Your Name"
opencode config set user.email "your.email@example.com"
```

## 基本使用示例

### 启动 OpenCode

```bash

# 创建新项目

opencode init

```

## 常见问题解决

### 安装权限问题

**问题**: 权限不足导致安装失败
**解决方案**:
```bash
# 使用 sudo 提升权限
sudo ./install.sh

# 或者修改安装目录权限
sudo chown -R $USER:$USER /usr/local/lib/opencode
```

### 网络连接问题

**问题**: 无法下载依赖包
**解决方案**:
```bash
# 配置代理
export HTTP_PROXY=http://proxy:port
export HTTPS_PROXY=https://proxy:port

# 使用国内镜像源
export NODE_OPTIONS="--registry=https://registry.npmmirror.com/"
```

### 磁盘空间不足

**问题**: 磁盘空间不足导致安装中断
**解决方案**:
```bash
# 清理缓存
opencode cache clean

# 删除旧版本
opencode cleanup

# 检查磁盘使用情况
df -h
```

### 环境变量冲突

**问题**: 环境变量设置错误
**解决方案**:
```bash
# 检查当前设置
echo $OPENCODE_HOME
echo $PATH

# 重新设置
unset OPENCODE_HOME
export OPENCODE_HOME="$HOME/.opencode"
export PATH="$OPENCODE_HOME/bin:$PATH"
```

## 故障排除

### 验证安装成功

```bash
# 检查版本
opencode --version

# 检查配置
opencode config list

# 测试基本功能
opencode help
```

### 日志查看

```bash
# 查看安装日志
cat ~/.opencode/logs/install.log

# 查看运行日志
cat ~/.opencode/logs/app.log

# 查看错误日志
cat ~/.opencode/logs/error.log
```

### 卸载 OpenCode

```bash
# 使用卸载脚本
./uninstall.sh

# 或手动清理
rm -rf ~/.opencode
rm -f /usr/local/bin/opencode*
```
